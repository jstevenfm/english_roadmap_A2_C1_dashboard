# English Roadmap — A2+ → C1

Personal 52-week English learning roadmap focused on software development.

## Features

- 52-week learning plan
- A2+ → B1 → B2 → C1 progression
- Listening-focused practice
- Weekly activities
- Progress tracking
- Personal notes
- Export/import progress as JSON
- No backend required
- Data stored locally in the browser

## Tech

- HTML
- CSS
- JavaScript
- LocalStorage
